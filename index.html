Web Architecture

Client-Server Model

The client-server model is a system where a client, such as a web browser, sends a request to a server. The server processes the request and sends a response back to the client.

Domain Name System (DNS)

DNS stands for Domain Name System. It translates domain names into IP addresses so that users can easily access websites without remembering numbers.

HTTP vs HTTPS

HTTP is used to transfer information between a browser and a web server. HTTPS is more secure because it uses encryption to help protect information.
